# APP SAP EF 2027 — versión 2

Editor de 12 SAP de Educación Física con validaciones desplegables del Excel original, edición individual por celda y exportación Word/PDF/JSON.

**Privacidad:** este repositorio público no contiene el archivo `plantillas.json` del preparador. Cárgalo desde el navegador. No subas a GitHub el JSON privado ni las SAP completas.

Para publicar en GitHub Pages, sube los archivos de este ZIP al repositorio público (conservando `.github/workflows/pages.yml` o el workflow de publicación ya existente). Settings → Pages → Source: GitHub Actions.

Los desplegables se obtienen de `validations` y de las columnas auxiliares del propio JSON original. Las opciones de cada celda son independientes. Los PDF y Word todavía no reproducen la maquetación exacta del Excel.
